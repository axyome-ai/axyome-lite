# Tutorials

Short, step-by-step guides that each end with something done. New to Axyome Lite? Start with
[the first five minutes](../onboarding.md).

| Level | Tutorial | Time | You will |
|---|---|---|---|
| Beginner | [Find a lost chat](find-a-lost-chat.md) | 5 min | Find last week's Copilot answer by project and date, open it and copy it |
| Beginner | [Share a chat safely](share-a-chat-safely.md) | 10 min | Export a Claude Code session for a pull request or a ticket, with secrets replaced, and check it before you share it |
| Beginner | [See your AI usage](see-your-ai-usage.md) | 5 min | Read the My chats page: chats per assistant and per day, largest chats, disk space and tokens |
| Intermediate | [Back up every chat from the terminal](back-up-all-chats-from-the-terminal.md) | 15 min | Export all your chats to Markdown files with one command, in bash or PowerShell, then only the new ones each week |
